# Capitalism Lab Realistic Difficulty

*A simple script that adjusts the game's difficulty to resemble reality. However, this doesn't necessarily mean it will be difficult.*

## How to use?

1. Download the [**`realistic_difficulty_v*.txt`**](https://github.com/KaioHSG/caplab-realistic-difficulty/releases/latest).
2. Place the downloaded file in the script directory (usually in `C:\Users\<Username>\Documents\My Games\Capitalism Lab\SCRIPT`).
3. Open Capitalism Lab and start a new custom game.
4. Go to **`LOAD SCRIPT`** > **`User-created Scripts`**.
5. Search for the **Realistic Difficulty file** and select it.
6. Press **`Load`**, then **`Start`**.

### Note

* You can modify some difficulty settings before you load the script. Or go to **`LOAD SCRIPT`** > **`User-created Scripts`** and set a different `Difficulty Level`.

## How to modify?

1. Upload [**`Realistic_Difficulty_settings.json`**](https://github.com/KaioHSG/caplab-realistic-difficulty/releases/latest) in [**Capitalism Lab Script Generator**](https://www.capitalismlab.com/script-generator-v12.html).
2. Make your modifications.
3. Use the **`Generate Script`** button.
